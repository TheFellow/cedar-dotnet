# 7152638 — Remove redundant entity_wrong_entity_ref corpus test

- Author: Patrick Jakubowski <patrick.jakubowski@delinea.com>
- Date: 2026-05-22

## Rationale

Upstream deletes a validate-test corpus file that was redundant: it used the implicit entity-reference JSON form which the unguided parser deserializes as `types.Record`, so the test was exercising the deserialization-error branch (already covered elsewhere) instead of the intended wrong-entity-type branch (which the `_explicit` sibling test already covers). Our C# port does not import this Go-side validator corpus (no matching `entity_wrong_entity_ref*` files exist under our tree), so there is nothing to delete on our side.
