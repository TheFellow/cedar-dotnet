# 097843c — Use explicit `__entity` form in `entity_type_mismatches` testdata

- **Author:** Patrick Jakubowski <patrick.jakubowski@delinea.com>
- **Date:** 2026-05-22T09:36:54-07:00
- **Subject:** Use explicit `__entity` form in `entity_type_mismatches` testdata

## Rationale

Test-data only fix for Go's `x/exp/schema/validate` corpus test. The `friend`
attribute was using the implicit `{"type":..., "id":...}` JSON shape, which the
unguided JSON parser there decodes as `types.Record` rather than an entity
reference, leading to flaky coverage of the `BoolType` error branch due to Go's
randomized map iteration order. Switching to the explicit `__entity` wrapper
makes the parse deterministic.

The C# port does not currently ship the `x/exp/schema/validate` validator nor
its corpus testdata, so there is nothing to update on our side. If/when that
validator is ported, the testdata will be carried over already in its fixed
form.
